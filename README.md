# Python Foundations and Applied Projects

Ce dépôt rassemble quatre travaux pratiques retravaillés pour présenter une progression en programmation Python et en résolution de problèmes appliqués.

## Projets

1. **Population Census Analysis** — fonctions, calculs démographiques, conditions et tests.
2. **Smart Grid Management** — programmation orientée objet, dataclasses, fonctions et listes.
3. **Morocco Desalination Program** — parsing CSV, structures de données, boucles, statistiques simples et tests.
4. **RSU Household Assessment (academic exercise)** — validation, dataclasses, fichiers CSV, calcul de score et rapport.

## Organisation

- `01_population_census.ipynb`
- `02_smart_grid_management.ipynb`
- `03_morocco_desalination.ipynb`
- `04_rsu_household_assessment.ipynb`

## Exécution

Les notebooks sont conçus pour Python 3 et peuvent être ouverts avec Jupyter Notebook, JupyterLab ou Google Colab. Les bibliothèques utilisées sont principalement celles de la bibliothèque standard Python.

## Notes méthodologiques

- Les données du TP3 sont conservées comme données pédagogiques fournies dans l'exercice ; elles ne sont pas certifiées comme données officielles.
- Les coefficients et le seuil du TP4 sont repris du travail initial. Le notebook est un exercice académique et ne doit pas être utilisé pour prendre une décision réelle d'éligibilité.
- Pour le TP1, ajouter dans cette documentation les références officielles si les chiffres de recensement mentionnés dans le contexte sont présentés comme des statistiques factuelles.
- Les notebooks ont été réorganisés, commentés et complétés par des validations/tests. Les changements de logique sont explicités dans les sections concernées.
